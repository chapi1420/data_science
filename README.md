# Data Science & Machine Learning Portfolio

A structured repository showcasing my technical proficiency across the Python data ecosystem. This project serves as a comprehensive roadmap from fundamental data manipulation to advanced deep learning architectures.

## 📌 Roadmap & Implementation Order

This repository is organized sequentially to reflect the standard data science workflow. Each directory contains Jupyter Notebooks, datasets, and documentation for specific projects.

---

### 1. [NumPy](./numpy/) — Fundamental Numerical Computing
* **Focus:** Vectorized operations, broadcasting, and linear algebra.
* **Implementation:** Building a "Neural Network from Scratch" to demonstrate understanding of backpropagation and matrix multiplication without high-level frameworks.

### 2. [Pandas](./pandas/) — Data Wrangling & Analysis
* **Focus:** Data cleaning, merging, pivot tables, and time-series analysis.
* **Implementation:** Exploratory Data Analysis (EDA) on a complex real-world dataset.

### 3. [Scikit-Learn](./scikit-learn/) — Classical Machine Learning
* **Focus:** Supervised/Unsupervised learning, Feature Scaling, and Model Selection.
* **Implementation:** An end-to-end Pipeline for predicting housing prices or customer churn, including hyperparameter tuning via `GridSearchCV`.



### 4. [TensorFlow](./tensorflow/) — Deep Learning & Production
* **Focus:** Keras API, Computational Graphs, and Image Processing.
* **Implementation:** A Convolutional Neural Network (CNN) for image classification with data augmentation and Transfer Learning.

### 5. [PyTorch](./pytorch/) — Research & Dynamic Graphs
* **Focus:** Autograd, custom training loops, and Natural Language Processing (NLP).
* **Implementation:** A Sentiment Analysis model using LSTMs or a Transformer-based architecture.

### 6. [Data Processing Tools](./data-processing/) — ETL & Pipelines
* **Focus:** SQL integration, API data fetching, and Big Data handling (Dask/PySpark).
* **Implementation:** A data pipeline that cleans and transforms raw JSON/API data into a structured format ready for modeling.

## ⚙️ Local Setup & Installation

To ensure reproducibility, this repository uses a Conda environment.

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/chapi1420/data_science](https://github.com/chapi1420/data_science)
    cd data-science
    ```

2.  **Create the Environment:**
    ```bash
    conda env create -f environment.yml
    conda activate ds_workspace
    ```

3.  **Launch Jupyter Lab:**
    ```bash
    jupyter lab
    ```

## 📊 Portfolio Philosophy
Each project in this repository follows the **PACE** framework:
* **P**lan: Define the problem and data sources.
* **A**nalyze: Clean and explore the data.
* **C**onstruct: Build and refine the model.
* **E**xecute: Interpret results and provide actionable insights.
